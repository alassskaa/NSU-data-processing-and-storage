# Строки без одинаковых соседних букв

По алфавиту из односимвольных строк и числу N функция
`words-without-repeats` возвращает все строки длины N, в которых нет двух
одинаковых букв подряд. Например, для `("a" "b" "c")` и N = 2 —
`("ab" "ac" "ba" "bc" "ca" "cb")`.

Требуется Java 17+ и [Clojure CLI](https://clojure.org/guides/install_clojure).

## Запуск

```bash
clojure -M:run 3 a b c
```

Первый аргумент — длина N, остальные — буквы алфавита. Без аргументов
выводится пример из условия (`a b c`, N = 2).

## Устройство

Без рекурсии, только `reduce`/`map`/`remove`:

- `reduce` по `(range n)` начинает с `[""]` и на каждом шаге удлиняет все
  строки на одну букву.
- Для строки `word` берутся буквы алфавита, кроме той, на которую `word`
  оканчивается (`remove` + `.endsWith`), и приклеиваются к ней через `.concat`.
- Продолжения всех строк собираются в один вектор через `(reduce into [] ...)`.

Для алфавита из k букв получается k · (k − 1)^(N − 1) строк. При N = 0
результат — одна пустая строка.
